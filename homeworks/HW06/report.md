## 1. Dataset

- Какой датасет выбран: `S06-hw-dataset-01.csv`
- Размер: (12000, 30)
- Целевая переменная: `target`  
  Классы и доли:
  - 0 — ~67.7%
  - 1 — ~32.3%
- Признаки:
  - числовые: 24 признака (`float64`)
  - целочисленные: 6 признаков (`int64`)
  - категориальные признаки отсутствуют (используются числовые кодировки)

Пропущенных значений в датасете нет.

## 2. Protocol

- Разбиение: train/test = 75% / 25%, `random_state=42`, стратифицированное по `target`
- Подбор:
  - GridSearchCV / RandomizedSearchCV
  - CV на train: 5 фолдов
  - Оптимизируемая метрика: ROC-AUC
- Метрики:
  - **Accuracy** — общая доля верных ответов
  - **F1-score** — баланс precision и recall, уместна при умеренном дисбалансе классов
  - **ROC-AUC** — основная метрика, устойчива к дисбалансу и отражает качество ранжирования

## 3. Models

Были обучены и сравнены следующие модели:

- **DummyClassifier**
  - Стратегия: `stratified`
- **LogisticRegression**
  - `C`, `penalty`, `solver`
- **DecisionTreeClassifier**
  - Контроль сложности через `max_depth`, `min_samples_leaf`
- **RandomForestClassifier**
  - `n_estimators`, `max_depth`, `min_samples_leaf`
- **GradientBoostingClassifier**
  - `n_estimators`, `learning_rate`, `max_depth`
- **AdaBoostClassifier**
  - `n_estimators`, `learning_rate`

Для всех моделей использовался единый ML-протокол и честное сравнение на test.

## 4. Results

Финальные метрики на test:

| Model                | Accuracy | F1-score | ROC-AUC |
|----------------------|----------|----------|---------|
| Gradient Boosting    | 0.9337   | 0.8932   | 0.9723  |
| Random Forest        | 0.9323   | 0.8904   | 0.9701  |
| AdaBoost             | 0.8540   | 0.7567   | 0.9150  |
| Decision Tree        | 0.8777   | 0.7965   | 0.9131  |
| Logistic Regression  | 0.8297   | 0.7147   | 0.8789  |
| Dummy Classifier     | 0.5623   | 0.3256   | 0.5008  |

**Победитель:** Gradient Boosting  
Причина: наилучшее значение ROC-AUC при высоких accuracy и F1-score, что говорит о хорошем качестве классификации и ранжирования.

## 5. Analysis

### Устойчивость
При изменении `random_state` (5 прогонов) для Random Forest и Gradient Boosting разброс ROC-AUC был минимальным (< 0.005), что говорит о высокой стабильности ансамблевых моделей.

### Ошибки
Confusion matrix для Gradient Boosting показывает:
- небольшое число FN (модель хорошо находит класс 1),
- FP присутствуют, но в разумных пределах.

Модель предпочитает немного жертвовать precision ради более высокого recall для положительного класса.

### Интерпретация
Permutation Importance (top-15) показала:
- наибольший вклад вносят признаки `num14`, `num07`, `num03`, `num01`
- влияние признаков распределено, нет одного доминирующего фактора

Сравнение с Random Forest показало схожий набор важных признаков, но с разным относительным вкладом.

## 6. Conclusion

- Ансамбли деревьев существенно превосходят линейные модели на данном датасете
- Boosting даёт максимальное качество при корректной настройке
- ROC-AUC — наиболее информативная метрика для данной задачи
- Контроль сложности деревьев критичен для обобщающей способности
- Permutation Importance даёт интерпретируемое и устойчивое объяснение модели
- Честный ML-протокол (CV + test) позволяет корректно сравнивать модели
